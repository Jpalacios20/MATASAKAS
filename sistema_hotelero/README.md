## Configuración

Define `APIS_TOKEN` en el entorno del servidor para habilitar las consultas de documentos. El envío de facturas por correo requiere `SMTP_HOST`, `SMTP_USERNAME` y `SMTP_PASSWORD`. Si se utiliza `application/config/Config2.php`, también deben definirse `DB_HOST`, `DB_NAME`, `DB_USER` y `DB_PASS`; `DB_PORT` es opcional y usa el puerto `3306` por defecto. No publiques certificados, comprobantes, exportaciones de bases de datos, logs ni credenciales.
